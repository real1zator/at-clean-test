# Переезды и грузоперевозки — Калининград и область

Одностраничный сайт: на ПК — обычный лендинг, на телефоне — интерфейс в стиле приложения (нижнее меню, плитки услуг), можно установить на главный экран.

## Что где менять

- **Название, телефон, WhatsApp, цены** — блок `CONFIG` в начале файла `app.js`.
- **Тексты, отзывы, реквизиты** — `index.html` (всё, что в квадратных скобках, — заглушки).
- **Цвета** — переменные в начале `styles.css` (`--accent`, `--mint`).

## Как работает заявка

Калькулятор считает примерную стоимость по ценам из `CONFIG`. Кнопка «Оформить заявку» открывает WhatsApp с готовым сообщением на ваш номер — сервер не нужен.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` (Settings → Pages).
